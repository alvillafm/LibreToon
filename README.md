# LibreToon

**LibreToon** is a free, open-source 2D animation software inspired by Adobe Animate, with the goal of combining traditional animation tools with more advanced features for creating animated scenes.

The project aims to bring together Adobe Animate's workflow, DragonBones-inspired rigging tools, and improved scene management, lighting, and camera controls.

<img src="https://i.imgur.com/GVQsCoT.png" width="700" alt="LibreToon Editor">

### Planned Features

- **Scene Manager:** Organize multiple scenes, each with its own timeline.
- **Bone Rigging:** Character animation tools inspired by DragonBones.
- **Lighting & Shading:** Dedicated brushes for easily adding light and shadows.
- **Filters & Effects:** Visual effects and post-processing tools.
- **Camera System:** Multiple cameras within a single scene, allowing camera cuts and different shots.
- **Animation Tools:** Traditional frame-by-frame and tween-based animation.

### Current Status

LibreToon is still in its early stages of development. Only the core application structure is currently implemented, with most of the features listed above planned for future updates.

The goal is to build a free, accessible, and community-driven alternative for 2D digital animation.
