# Learn by Making: The Little Owl

Five small projects introduce a few tools at a time. The teaching approach is incremental: make something recognizable, check it works, then add one new skill. No previous rigging experience is required.

| Lesson | You make | You learn |
| --- | --- | --- |
| [1 · Draw a Little Owl](01-owl.md) | A simple vector character | Shapes, fills, selection and color |
| [2 · Make the Owl Blink](02-blink.md) | A short blink | Keys, held exposures and onion skin |
| [3 · Build a Forest Shot](03-forest.md) | A moving camera shot | Layers, depth and framing |
| [4 · Light the Night](04-lighting.md) | A lit night scene | Light receivers, FX and preview |
| [5 · Rig a Waving Wing](05-rig.md) | A reusable wing pose | Symbols, bones and binding |

Save a separate `.ltoon` at each lesson. Lessons 3–5 can use a static copy from lesson 1; you do not need to finish every previous animation. The rig lesson deliberately starts from a clean static copy so the first rig is easy to diagnose.
