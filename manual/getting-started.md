# Workspace and First Steps

## Find your way around

| Area | What you do here |
| --- | --- |
| Home | Create projects and open recent projects or editable examples |
| Left toolbar | Choose drawing, selection and rigging tools |
| Stage | Draw, select, pose and inspect the camera view |
| Timeline below the stage | Choose layers and frames, edit timing and play |
| Properties | Adjust the active tool or selected item |
| Library / Animation / Color | Reuse assets, clips and colors |

Turn on **Command Helper** beside the timeline to see gestures for the current tool. Keyboard bindings can be changed in **File → Program Preferences → Keyboard Shortcuts**; check them if a tutorial shortcut differs from your setup.

## Create a small project

1. Choose **New Project** on Home.
2. Use **File → Document Settings** to set a 1280 × 720 stage. Set 24 fps and a short duration using the timeline controls.
3. Select an unlocked vector layer, marked **V**.
4. Choose a brush, draw a stroke, then undo it to check your input.
5. Use **File → Save As** to save a `.ltoon` project in a folder you recognize.

## Before moving on

Make a small visible edit, save again, and check that the document no longer indicates unsaved changes. Keep your first exercise separate from valuable production files.
